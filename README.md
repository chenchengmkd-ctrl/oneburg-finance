# 屋台うなぎ Birdmen 財務管理アプリ

## プロジェクト概要
株式会社ワンバーグが運営する屋台うなぎ Birdmen（神田駅近く）の
日次・週次・月次・借入返済の財務管理Webアプリ。

## 技術スタック
- **フロントエンド**: React + TypeScript + Vite
- **スタイリング**: Tailwind CSS
- **状態管理**: Zustand
- **データ永続化**: localStorage（将来的にSupabase移行想定）
- **グラフ**: Recharts
- **アイコン**: Lucide React

## セットアップ
```bash
npm install
npm run dev
```

## アーキテクチャ

### データ設計（localStorage キー）
- `birdmen:settings` - 初期設定（月初残高・月予算等）
- `birdmen:daily:{YYYY-MM-DD}` - 日次データ
- `birdmen:weekly_budget:{YYYY-WW}` - 週次予算
- `birdmen:monthly_budget:{YYYY-MM}` - 月次予算・固定費
- `birdmen:loans` - 借入残高管理
- `birdmen:personal_expenses` - 個人支出予定

### 画面構成
1. **ダッシュボード** - 今日の収支サマリー、法人・個人残高、予想残高
2. **日次入力** - 日別の売上・支出・残高入力
3. **週次レビュー** - 週次実績vs予算、銀行残高照合
4. **月次管理** - 月次予算・固定費・変動費・収支差額
5. **借入返済管理** - 残高・返済余力シミュレーション（日次ベース）

## 連動ロジック
- 日次データ → 週次自動集計 → 月次自動集計
- 日次残高（法人・個人）→ 予想残高を前日残高+当日収支で計算
- 個人口座 - 個人支出予定 = 返済可能予想額
- 法人余剰 + 個人返済可能額 = 月次返済余力

## 主要な計算ロジック

### 予想残高
```
法人予想残高(今日) = 昨日の法人実残高(or月初残高) + 今日の法人収支
個人予想残高(今日) = 昨日の個人実残高(or月初残高) + 今日の個人収入
合計予想残高 = 法人予想 + 個人予想
```

### 週次集計
```
週次実績 = SUM(その週の日次データ)
週次達成率 = 週次実績 / 週次予算
週次差異 = 週次実績 - 週次予算
```

### 借入返済余力
```
法人余剰 = 法人収入 - 固定費 - 変動費
個人返済可能額 = 個人口座残高 - 個人支出予定合計 - 生活費バッファ
月次返済余力 = MIN(法人余剰, 法人余剰) + 個人返済可能額
```

## 借入返済管理（日次）
- 毎日の法人余剰・個人余剰を表示
- 累計返済可能予想額をリアルタイム計算
- 個人支出予定（家賃・通信費等）を登録して自動差し引き
- ヤマシタさん残高の完済予定日を試算
